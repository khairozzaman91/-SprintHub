# SprintHub

A modern full-stack project management system built with React, TypeScript, Tailwind CSS, Go, Fiber, and PostgreSQL.

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- React Router

### Backend
- Go
- Fiber
- PostgreSQL
- JWT Authentication

## Features
- Authentication
- Dashboard
- Project Management
- Task Management
- Team Collaboration
- Reports
- Calendar
- Responsive Design

🚧 Project is under development.
