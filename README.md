# SprintHub

A modern full-stack project management system built with React, TypeScript, Tailwind CSS, Go (Fiber), and PostgreSQL.

> 🚧 This project is currently under active development.

---

## 🚀 Tech Stack

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS v4
- React Router DOM

### Backend

- Go (Golang)
- Fiber
- PostgreSQL
- JWT Authentication

## 🛠️ Getting Started

### Clone the repository

```bash

```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
